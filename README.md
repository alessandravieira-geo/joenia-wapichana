# Site Joenia Wapichana

Landing page em React + Vite inspirada no mockup criado para o projeto.

## Rodar localmente

1. Instale Node.js (versão 18 ou superior).
2. Abra esta pasta no terminal.
3. Execute:

```bash
npm install
npm run dev
```

4. Abra o endereço mostrado pelo Vite, normalmente `http://localhost:5173`.

## Gerar versão para publicação

```bash
npm run build
```

A pasta `dist/` poderá ser publicada em serviços como Vercel, Netlify ou GitHub Pages.

## Estrutura

- `src/main.jsx` — conteúdo e componentes da página.
- `src/styles.css` — identidade visual completa.
- `public/assets/joenia-portrait.png` — ilustração principal.
- `public/assets/botanical-border.svg` — decoração vegetal.

## Observação

O conteúdo biográfico inicial foi montado a partir de informações públicas oficiais da Câmara dos Deputados e da Funai. Antes de uma publicação definitiva, recomenda-se acrescentar uma página de fontes/referências e revisar os textos conforme o objetivo pedagógico do projeto.
